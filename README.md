# CSC450-1 Module 1 - Person Information Program

A C++ console application that demonstrates variable declaration, string data types, variable assignment, and formatted output.

## Overview

This project was developed for Module 1 of CSC450-1. The program stores fictional personal information in string variables and displays each value in the console. It introduces foundational C++ programming concepts, including variable declaration, assignment statements, and output using `cout`.

## Features

- Declares string variables for personal information.
- Assigns sample values to each variable.
- Displays a person's first name, last name, street address, city, and ZIP code.
- Uses formatted console output to organize the results.
- Compiles with the Clang++ compiler in Eclipse IDE.

## How It Works

The program declares five string variables to store fictional personal information. It assigns a value to each variable and uses `cout` to display the information in the console. Each output statement labels the information so the results are easy to read.

## How to Run

1. Open the project in Eclipse IDE.
2. Build the C++ project using the configured Clang++ toolchain.
3. Run the compiled executable.
4. View the displayed personal information in the console.

The program can also be compiled from a terminal with Clang++:

```bash
clang++ -std=c++17 PersonInfo.cpp -o PersonInfo
./PersonInfo
```
